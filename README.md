# Django学生考勤管理系统分享

## 核心功能
- 登录注册
- 学生考勤管理
- 考勤统计管理
- 签到记录管理
- 请假记录管理
- 学生管理
- 科目管理
- 教师管理
- 班级管理
- 系统管理
- 用户信息管理
- 数据可视化分析

- 学校和教育机构
- 管理学生考勤记录
